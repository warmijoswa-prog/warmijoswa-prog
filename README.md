## Process automation

**How I work**

- Excel and VBA: macros, UserForms, embedded queries and parameter-driven workbooks
- Self-service tools that let users run their own reports and analyses without technical support
- Complex SQL on Oracle: writing, tuning and optimizing queries to cut execution time
- Process optimization and standardization across teams
- Continuous improvement of every tool after delivery

**What I have automated**

- **Proactive degradation detection:** finds the sites with the greatest new degradation across Radio Access Network KPIs for 2G, 3G, 4G, 5G, for data and voice services like VoLTE, efficiencies, traffic, RTWP, drop calls, CCR, CSFR, RSSR, transmission faults: S1 interface, frame loss.
- **Regulatory reporting:** 11 quarterly reports for the national telecommunications regulator, with 100% on-time delivery and not a single fine to the operator for late submission.
- **Incident notifications:** automatic emails to the business with network incident information, generated by querying the trouble-ticket database.
- **OTT traffic control:** daily tracking of traffic for the main OTT platforms (TikTok, WhatsApp, Facebook, Instagram, YouTube and others) using Sandvine DPI.
- **Management-system emulator:** an emulator of the management system for Ericsson TDMA switches.
- **Market and network reporting:** reports combining network data with external sources such as Facebook Actionable Insights, Ookla Speedtest and Tutela, with multiple time granularities, maps and benchmarking against competing operators.
- **Core network reporting:** IP core reports (SLAview) and IMS voice core reports.
- **Dashboards:** QlikView dashboards, and Grafana dashboards on BMC Helix Remedy, the trouble-ticket platform.
